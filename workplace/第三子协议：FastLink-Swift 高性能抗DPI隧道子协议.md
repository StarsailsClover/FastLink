## 一、定位与职责

### 核心定位

FastLink 生态**专用流量隧道 \&amp; 抗审查 \&amp; 多路径聚合**子协议。
承担三大核心能力：

1. 全域流量封装、透明代理隧道

2. 深度 DPI 伪装、协议混淆、QoS 规避

3. 多链路带宽聚合、流量负载均衡

### 核心约束（继承母协议铁律）

1. 不重复实现加密、报文头、握手流程，全盘复用母协议标准

2. 依附母协议调度器，自动优选 P2P/Server 链路做隧道承载

3. 所有伪装策略内置，适配国内三大运营商 DPI 特征库

4. 隧道链路质量波动时，由母协议无感迁移，业务不断流

5. 严格端到端加密，隧道中间节点无法解析内层流量

## 二、技术背景与行业痛点

1. 常规隧道协议（WireGuard/OpenVPN）特征固定，极易被 DPI 精准识别封禁

2. 单链路带宽上限受限，无法叠加多宽带、多运营商带宽

3. 国内运营商存在小包限流、固定心跳检测、端口特征风控

4. 传统隧道无流量整形、无时序随机化，流量画像一眼可识别

5. 链路断线重连生硬，游戏 / 直播业务会卡顿掉线

## 三、核心原理拆分

1. **全栈 HTTPS 原生伪装原理**
复用真实域名 / 证书 / TLS 指纹 / HTTP 头，把隧道流量完全伪装成普通浏览器 HTTPS 访问，DPI 无法区分。

2. **多路径分片聚合原理**
将原始流量均等分片，分发到多条 P2P/Server 链路并行传输，接收端乱序重组，叠加带宽、降低延迟。

3. **QoS 五维规避原理**
流量整形 \+ 端口跳变 \+ 协议混淆 \+ 时序抖动 \+ 包长随机化，破坏运营商风控识别特征。

4. **动态特征轮换原理**
定时轮换伪装域名、TLS 指纹、端口区间、心跳间隔，避免长期固定特征被标记。

5. **无感链路热迁移原理**
母协议调度层后台预建备选隧道链路，切换时迁移会话、序列号、滑动窗口，上层零感知。

## 五、技术与核心细节

### 5\.1 隧道封装格式

外层：**母协议标准 28B 通用报文头**
内层：原始 IP/TCP/UDP 载荷 \+ 分片序号 \+ 校验标识
全程 AES\-256\-GCM 加密，外层看起来完全是标准 HTTPS 流量。

### 5\.2 TLS 伪装核心细节

- 内置 200 \+ 主流国内域名真实 SSL 证书池

- 完全复刻 Chrome 密码套件顺序、扩展列表、椭圆曲线、ALPN

- Client Hello / Server Hello 字段完全和正版浏览器一致

- 每 30 分钟自动轮换域名、证书、指纹配置

### 5\.3 多路径聚合算法

- MTU 固定分片：1300 字节 / 片，避免链路分片

- 按链路质量权重轮询分发分片

- 接收端建立滑动重组窗口，乱序等待、超时重传

- 支持 FEC 前向纠错，5% 以内丢包无需重传

### 5\.4 QoS 规避五件套

1. **流量整形**：发包速率平滑化，抑制突发峰值

2. **端口跳变**：每 10 秒自动切换 443 附近随机端口

3. **协议混淆**：载荷随机弱加密填充，无固定字节特征

4. **时序抖动**：发包间隔 ±5ms 高斯随机，规避固定心跳

5. **包长随机化**：尾部随机填充冗余字节，消除固定包长指纹

## 七、边界情况处理

1. 单条隧道链路丢包飙升 → 自动分流到其他可用链路，不降速

2. 伪装域名被本地 DNS 污染 → 自动切换备用域名池，跳过解析

3. 多路径其中一条断线 → 自动剔除链路，剩余链路自适应均分流量

4. 防火墙非 80/443 端口拦截 → 强制锁定 443 端口常驻伪装

5. 分片乱序严重 → 扩大重组窗口，适度超时等待，保障业务连贯

## 八、最坏场景与四级兜底

1. 最坏场景：全量 HTTPS 特征被深度风控、多链路全部阻断、域名全污染

2. L1 兜底：切换 WebSocket 伪装模式，混在普通网页长连接流量

3. L2 兜底：降级极简混淆，仅保留加密不做复杂伪装

4. L3 兜底：退回纯 TCP 直连隧道，牺牲伪装保连通

5. L4 兜底：隧道不可用时自动切本地直连，不阻断用户上网
